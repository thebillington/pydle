Quick Help

                
            

            

                
Getting started

                
Write Python in the editor on the left. Press Ctrl+Enter or click Run to try it, and the result appears in the console on the right.

                
print("Hello, World!")


                
Projects and files

                
When no project is open, the home screen lists every project on this device. Choose one to carry on, or create a new one and give it a name and a first file.

                
A project is a folder for one piece of work, and it can hold several files. The rail down the left side lists the files in the open project, and the project name at the top of the rail takes you back to the home screen. Use the rail to add a file, rename one or delete one.

                
The rail also lists any libraries that the project's requirements.txt declares. This is a read-only reminder for now.

                
Save keeps the file you are working on safe on this device.


                
Saving your work

                
Press Ctrl+S, or the save button, to save. That always keeps your work on this device, so nothing is lost if the connection drops.

                
If you are signed in to GitHub, saving also asks for a short message and gives you a list of the files that changed. Press commit and a copy goes into your own GitHub repository. That copy is what follows you to another computer.

                
If you are not signed in, saving only keeps the work on this device. The save button shows a small dot until your work is in GitHub, and the button in the header connects you.

                
Your GitHub copy

                
To commit, sign in from the GitHub button in the header. pydle stores your projects in a repository that belongs to your account, and you can change your mind and stop at any time.

                
Nothing is shared with anyone else. The repository is yours: you can look at it, change it or delete it whenever you like.


                
History

                
Every commit is kept. Open a project, then use the history button in the toolbar to see its earlier versions.

                
Choose any earlier version to look at it, or load it back into the editor and commit it again as a new change. Nothing is ever rewritten.


                
When a run fails

                
If your code stops with an error, the line that raised it is marked beside the line numbers and scrolled into view, so you can see where to start looking.

Appearance

                
The theme control in the header cycles through Auto, Light and Dark. Auto follows your computer's own setting, and pydle remembers the choice for next time.
