Get your GitHub account ready for pydle

Do this at home or in a club. Not in the lesson, and not on the school network. It takes about 15 minutes.

You must be 13 or older. GitHub accounts are only for people aged 13 and over. If you are 12 or younger, stop here and tell your teacher. You can still use pydle without GitHub, and you will not lose anything you need for the lesson.

Do not do this at school. Many accounts from one school address in a short time can be slowed, blocked or suspended by GitHub, and a suspended account takes weeks to get back. Use a home connection, or a phone on mobile data.

Part 1: make a GitHub account

Skip this part if you already have an account you can sign in to.

  1. Open github.com/signup.
  2. Enter your email address, a password, and a username. Your username is public, so do not use your full name.
  3. Check your email for a code and type it in. Look in junk and spam. If nothing arrives after 10 minutes, tell your teacher rather than pressing resend over and over.
  4. Choose the Free plan. You never need to pay for anything.
  5. Answer or skip the questions that follow. They do not affect anything.

Part 2: connect pydle

  1. Open pydle.uk and click GitHub in the top right.
  2. Click Sign in with GitHub.
  3. pydle shows a short code, like WDJB-MJHT. Copy it.
  4. Open github.com/login/device.
  1. Sign in if GitHub asks, then type or paste the code and press Continue.
  2. Check the page says pydle, then press Authorize.
  3. Go back to pydle and press Create my repository. It is private, so only you can see it.

Never give the code to anyone. Only type it on github.com, on a page you opened yourself. A code someone sends you, or someone asking for it, is not from pydle. If you are not sure, close the tab and ask your teacher.

Check that it worked

  1. In pydle, make a project called hello, run it, then press Commit and write a short message.
  2. Open github.com/your-username/pydle-workspace in a new tab. Your project should be there.
  3. The GitHub button in pydle should show a green dot from now on.

If something goes wrong

What you seeWhat to do
github.com will not loadThe school network may block it. Try at home, and tell your teacher.
No email with a codeCheck junk and spam. If it is not there, tell your teacher.
"That code expired"The code lasts 15 minutes. Click Sign in with GitHub again for a new one.
It says you are signed in as someone elsePress Forget this device in pydle, then sign in again.
