A Trinket alternative for Python and turtle

Trinket shut down on 31 August 2026. pydle runs Python and turtle in the browser with no account and no server, and you can host your own copy. It covers the Python and turtle part of Trinket.

Open the Python editor Open the turtle editor

What pydle does

  • Python and turtle in the browser, with no account.
  • Work saved in that browser, downloaded as .py, and committed to a repository the student owns.
  • MIT licensed and static, so a school can deploy its own copy.

Git, without the terminal

Signing in with GitHub puts each project in a private repository the student owns. Saving is automatic on the device. Committing is a separate step, with a message and a diff of what changed, and every commit is kept.

That is the part of git a beginner needs: what changed, why, and how to get last week's version back. No clone, no branch, no command line. The sign-in is optional, and GitHub accounts are for people aged 13 and over.

What happened to Trinket

Trinket announced its closure in 2026 and closed on 31 August 2026. The site, its embeds and its hosted projects went offline. A community copy of the open-sourced editor runs at trinket.strivemath.org, without the old accounts or content. Any surviving Trinket embed has to be replaced with code and a link.

Moving a Trinket program across

  1. Copy the Python code from the old trinket.
  2. Open pydle, or the turtle editor if it uses import turtle.
  3. Paste it, press Run, and fix anything that depends on Trinket.
  4. Download the .py or leave it in browser storage.

Questions

Did Trinket shut down?

Yes. It announced its closure in 2026 and closed on 31 August 2026. Existing embeds and links stopped working.

Is pydle a drop-in replacement?

For Python and turtle programs, yes. Copy the code across and run it.

Can I move a program across?

Copy the code into pydle and run it. Anything that depends on a Trinket-only feature needs changing.

Do students need GitHub?

No. It is optional, and GitHub accounts are for people aged 13 and over.

Can we host it ourselves?

Yes. pydle is MIT licensed and static. GitHub sync needs your own OAuth app and relay, which is the only part to maintain.
