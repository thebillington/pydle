Python turtle in the browser

pydle runs CPython in the browser through Pyodide, with a turtle that draws to a canvas. No install, no account and no server. You can also host your own copy.

Open the turtle editor Open the Python REPL

What runs

Real CPython, not a Python-like language. Turtle programs draw as they run, with loops, functions, colours and fills. Programs save to that browser, download as .py, and can be committed to a repository the student owns.

The turtle is a compatibility layer, not Tkinter. Most lesson programs work. Programs that open tkinter windows, dialogs or custom screens do not.

Run your own copy

pydle is MIT licensed, static and has no build step. Fork the repository and publish it on GitHub Pages or Cloudflare Pages, and that is the deployment. GitHub sync is the only part that needs something of yours. That is an OAuth app and a small CORS relay, set in js/config.js. Everything else works without it.

Questions

Does it work on a Chromebook or school laptop?

Any browser with WebAssembly. Chromebooks, Windows laptops, Macs, Linux machines, iPads and phones all run it.

Is it free?

Yes, MIT licensed, with no account and no paid tier. You can host it yourself.

Can I save a program?

Save it in that browser, download it as a .py, or commit it to a GitHub repository if you sign in.

Is this the same as desktop turtle?

It is a compatibility layer written for the browser. Most turtle programs work. Tkinter windows and dialogs do not exist here.

Getting started

Open the turtle editor, press Run, then change a number, a colour or a loop count. Help has the shortcuts and a short example.
