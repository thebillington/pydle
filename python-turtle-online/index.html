What you get

Real Python

pydle runs CPython compiled to WebAssembly with Pyodide. It is not a Python-like toy language or a transpiler.

Turtle graphics

A browser turtle implementation draws to a canvas, so loops, functions, colours and patterns appear as the program runs.

Nothing to install

No Python download, no pip, no Tkinter setup and no administrator rights. If the browser runs, pydle runs.

Your code stays local

Saved programs live in browser storage. You can download any program as a normal .py file.

Who it is for

pydle is aimed at the awkward middle ground between block editors and a full desktop IDE: students who are ready to type Python but should not lose a lesson to installing an interpreter. It also works well for a quick experiment on a phone or tablet, or for a teacher who wants a turtle example on screen without touching the lab image.

Turtle, REPL or both?

Use the turtle editor for drawing and animation. Use the main REPL for console programs, loops, functions and quick experiments. Both save locally and both can download a .py file.

Frequently asked questions

Is the pydle turtle editor free?

Yes. pydle is free to use and does not require an account, a subscription or a payment.

Do I need to install Python to use it?

No. Python runs inside your browser using Pyodide and WebAssembly, so there is nothing to install and no server-side runtime.

Does it work on a Chromebook or school laptop?

Yes, provided the browser supports WebAssembly and JavaScript. It runs in a normal browser tab on Chromebooks, Windows laptops, Macs, Linux machines, iPads and phones.

Can I save my turtle program?

Yes. Programs can be saved in your browser's local storage and downloaded as a .py file. Saved files stay in that browser unless you download them.

Is this the same as desktop Python turtle?

It uses a compatibility layer built for the browser rather than Tkinter. Common turtle programs work, but it is not a complete clone of desktop turtle and some desktop-only behaviour may differ.

Do I need to create an account?

No. There is no signup, no login and no student account. Open the editor and run code.

Getting started

Open the turtle editor. The starter program is a complete turtle example. Press Run, then change a number, a colour or a loop count and run it again. Press Help for the keyboard shortcuts and a short guided example.
